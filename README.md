# Media Knowledge Extractor (MKE)

A local-first Python application that transforms audio and video
into structured, searchable knowledge.

## Planned Features

- Audio and video transcription (Greek and English)
- Speaker diarization
- Extraction of relevant slides, diagrams and images
- Microsoft Word document generation
- Preservation of original transcripts
- CLI with progress tracking
- Resumable processing
- Local AI models

## Project Status

Early development.
